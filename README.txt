# PUPILETRAS EDUCATIVAS

Aplicativo web/PWA funcional para III, IV y V ciclo.

## Funciones incluidas
- Pupiletras interactivas.
- Palabras alrededor de la cuadrícula.
- Selección táctil: primera y última letra.
- Direcciones horizontales, verticales y diagonales.
- Niveles 1, 2 y 3.
- Comunicación, Ciencia y Tecnología, Personal Social y Matemática.
- Módulo inicial de lectoescritura para III ciclo.
- Lectura de palabras mediante voz del dispositivo.
- Pistas.
- Mini desafío de comprensión.
- Modo docente: escribir palabras y generar una nueva pupiletras.
- Contextualización con vocabulario del Valle Fortaleza/Pocor.
- Funcionamiento offline después de la primera carga.
- Instalable como PWA en Android/tablet cuando se sirve por HTTPS.

## Cómo probar
1. Descomprime el ZIP.
2. Para una prueba rápida abre `index.html` en un navegador moderno.
3. Para instalar como PWA y usar offline, publica la carpeta en un servidor HTTPS (por ejemplo, GitHub Pages, Netlify o similar).
4. En Android/Chrome usa "Instalar aplicación" o "Añadir a pantalla de inicio".
